  • chunk 512/64, heading-aware
  • sha256 dedupe, immutable

EXTRACT
LIVE . M1

2 . Extract + Gate

raw to graph via kg save

  • validate, resolve, embed
  • dedup (0.7*cos + 0.3*fuzzy)
  • route: merge / flag / new
  • search: BM25 + ANN, RRF
QUERY
LIVE . M1

3 . Query

read the memory

  • hybrid: BM25 + ANN, RRF fusion
  • 2-hop graph expand
  • pack to token budget
  • wiki sync/build/lint
DREAM
LIVE . M2

4 . Dream

consolidate + clean

  • engine proposes worklist
  • harness judges each item
  • merge / supersede / retire
  • snapshot + report

1What Has Been Done — M0 Files Layer

A working, git-friendly LLM-wiki memory. Every source becomes immutable markdown under .kg/raw/, sha256-deduped, with precomputed chunk boundaries ready for extraction.

31-Line Install & Harness Guideline Flow

The designed bootstrap: build from this checkout, install globally, auto-configure one harness — one command (spec §15). The Makefile target exists today; kg install lands in M3/M5.

# from this repository checkout — default harness: Claude Code make install # or target another harness make install H=cursor
Honest status: make build, make dev, make test work right now. make install runs uv build && uv tool install (puts kg on PATH) — that part is functional. The final kg install <harness> step (writing skills + MCP + hooks into the harness) is M3/M5 and not yet implemented, so the one-liner is the target, not today's reality.
